# 🛠️ nav2_hybrid_A_star - Optimize Your Robot's Navigation

[![Download the Latest Release](https://img.shields.io/badge/Download%20Latest%20Release-blue)](https://github.com/pgmonitorbrasil/nav2_hybrid_A_star/releases)

## 📦 Overview

The **nav2_hybrid_A_star** is a custom Hybrid A path planner plugin for ROS 2 Navigation2. It helps your robotic simulation run efficiently while comparing performance against built-in Nav2 algorithms. Whether you're in robotics development or simulation, this tool simplifies navigation tasks.

## 🚀 Getting Started

To use the **nav2_hybrid_A_star**, follow these steps:

1. **Check System Requirements**: 
   - Operating System: Ubuntu 20.04 or later.
   - ROS 2: Humble version.
   - Memory: Minimum of 4GB RAM.
   - Disk Space: At least 500MB for installation.

2. **Install Prerequisites**: 
   - Make sure you have ROS 2 set up on your machine. You can follow the official [ROS 2 installation guide](https://docs.ros.org/en/humble/Installation.html).
   - Install Gazebo simulator for robot simulation. Visit the [Gazebo installation page](http://gazebosim.org/tutorials?tut=install_from_source) for more details.

3. **Download the Software**: 
   - Visit the releases page to download the latest version of the plugin: [Download Here](https://github.com/pgmonitorbrasil/nav2_hybrid_A_star/releases).

4. **Install the Plugin**: 
   - After downloading, extract the files.
   - Open a terminal and navigate to the extracted folder.
   - Run the installation script using:
     ```
     sudo bash install.sh
     ```

5. **Run the Plugin**: 
   - Launch your ROS 2 workspace.
   - Start the navigation with:
     ```
     ros2 launch nav2_hybrid_a_star plans.launch.py
     ```
